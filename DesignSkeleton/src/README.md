# LLD

Low-level design interview practice focused on object-oriented design, design
patterns, and core business logic.

## Practice Roadmap

Work through the following problems in priority order.

| Priority | LLD Problem                     | Concepts Tested |
|:--------:|---------------------------------| --- |
|  **1**   | **Splitwise / Expense Sharing** | Strategy pattern, balance calculation |
|  **2**   | **Vending Machine**             | State pattern |
|  **3**   | **ATM System**                  | State pattern, transaction handling |
|  **4**   | **Library Management**          | Object-oriented programming, relationships |
|  **5**   | **Chess / Tic-Tac-Toe**         | Composition, game rules |
|  **6**   | **Amazon Shopping Cart**        | Pricing, discounts, inventory |
|  **7**   | **Meeting Room Booking**        | Concurrency, time-slot conflicts |
|  **8**   | **Hotel Reservation**           | Availability, booking lifecycle |
|  **9**   | **In-memory File System**       | Composite pattern, tree structure |
|  **10**  | **Pub/Sub Messaging System**    | Observer pattern, asynchronous processing |
